# Validation notes

## Calibrated range coverage

The reported 94.9% hotspot and 93.9% fire-power coverage figures are useful checks, but they are not independent estimates of coverage. Although factors used to predict 2012–2015 were fitted without those years, those observations influenced which 1,743 cells and months were evaluated, their weights, range calibration, and model selection. The evaluated bands also differ from the published pre-2012 ranges. The website therefore labels the 95% ranges as conversion error only, not a guaranteed bound on the true value.

## Backward error

The approximately 4% backward error is the fire-weighted median absolute error of each tested 2.5° cell's total over all 48 months of 2012–2015, with factors fitted on 2016–2019. It is not a typical monthly error. The typical single cell-month error is 17.6% for hotspots and 21.9% for fire power.

## Independence of checks

The simple-method comparison is not fully independent of the choices used to select the production method. A clean refit on 2012–2019 would be a sensitivity analysis, not independent validation. A genuine outer holdout would require S-NPP observations unused by any model choice or range calibration. Published ranges should not be recalibrated on an evaluation set and then reported as validated on that same set.
